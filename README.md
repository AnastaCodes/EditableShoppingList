# Editable Shopping List

**A shopping/to-do list with inline editing — change your mind without retyping.**

![Editable Shopping List screenshot](docs/screenshot.jpg)

**[Try it live →](https://anastacodes.github.io/EditableShoppingList/)**

## Features

- Everything from [BasicToDoList](https://github.com/AnastaCodes/BasicToDoList): add, complete, delete, bulk-clear
- **Inline editing** — click edit, change the text in place, save
- List persists across sessions via `localStorage`
- Built with vanilla HTML, CSS and JavaScript — no dependencies

## Run locally

```bash
git clone https://github.com/AnastaCodes/EditableShoppingList.git
open EditableShoppingList/index.html
```
